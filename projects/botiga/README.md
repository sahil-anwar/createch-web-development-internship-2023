# Botiga — Multi-page storefront frontend

An original-design-preserving frontend project from my 2023 web development internship portfolio at **Createch IT Solutions (SMC) Pvt. Ltd.**

## Pages
- Home (`botiga.html` / `index.html`)
- Shop (`shop.html`)
- Blog (`blog.html`)
- Contact (`contact.html`)
- Profile (`profile.html`)
- Cart (`cart.html`)

## Technology
HTML5, CSS3, responsive layout techniques, and minimal vanilla JavaScript for the mobile menu.

## Run locally
Open `index.html` in a browser, or use `python -m http.server 8000` from this directory and visit `http://localhost:8000/`.

## Preservation and improvements
The original visual design, pages, and supplied images are retained. The 2026 maintenance pass adds a working accessible mobile navigation toggle, small-screen layout safeguards, keyboard focus styles, reduced-motion support, image lazy loading, and an index entry point. Original CSS is left in `style.css`; fixes are isolated in `enhancements.css` and `enhancements.js`.

## Scope
This is a frontend demonstration. Cart, account, search, and checkout visuals should not be mistaken for production backend integrations. Product imagery and brand elements may belong to their respective rights holders; verify permissions before public publication.
